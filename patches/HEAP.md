# Heap-патч для master

[0003-use-stable-heap-pathfinding.patch](0003-use-stable-heap-pathfinding.patch)
заменяет связный список открытых узлов на стабильный бинарный min-heap.

База: **`0716b47205e297375d7a3848d923d5ce916eba6d`** (`master`).
Рабочая ветка синхронизирована с этой версией; сам heap **не применён**
к `src/Game.java`, чтобы можно было сравнить контрольную и изменённую сборки.

## Применить

Из корня checkout этой ветки или совместимого master:

```sh
git apply --check patches/0003-use-stable-heap-pathfinding.patch
git apply patches/0003-use-stable-heap-pathfinding.patch
```

Не применяйте перед этим `0001`/`0002`: они предназначены для старого
`785ef00`, а новый master уже содержит свои версии первых оптимизаций.

Откат только heap:

```sh
git apply --reverse --check patches/0003-use-stable-heap-pathfinding.patch
git apply --reverse patches/0003-use-stable-heap-pathfinding.patch
```

Если master изменится, сначала проверьте применимость через `--check`.

## Область изменений

- Только `src/Game.java`, только регион Pathfinding.
- Сохранён FIFO при одинаковом `G + H`, включая remove/reinsert.
- Учтено, что `nodeG[n]` обновляется до удаления; произвольное удаление
  использует position map и просеивание в обе стороны.
- Эвристика, стоимости, коллизии, порядок соседей, traceback и буферы прежние.
- AI, счётчик `lag`, тайлы и сортировка раз в восемь тиков не меняются.
- Дополнительный payload на карте 96×93 — **35 712 байт**, плюс заголовок
  массива/поля: около **35 KiB**. Внутри поиска память не выделяется.

## Проверки

[Результаты проверки этой версии патча](0003-heap-validation.txt).

Обе полные сборки — master и master + heap — скомпилированы Java 1.3
и прошли CLDC-preverification (45.3/StackMap). На desktop Java и оригинальном
KVM 1.1, на каждом VM, прошли **20 644** проверки состояния очереди и **656**
точных сравнений поиска: буфер результата, visited/expansion order, parent/G/H,
членство/позиции и очистка workspace.

Offline-тесты применения/отката и исторических экспортов:

```sh
python3 -m unittest discover -s benchmarks/kvm -p 'test_run.py' -v
```

## Замер в PSPKVM

Этот heap-патч агентом **не измерялся в PSPKVM**. Пользовательский результат
`1390 → 1060 ms` получен **без heap** и не является результатом этого патча.

Сравнивайте две сборки одного master — без патча и с `0003`, на одинаковом save
и настройках, с несколькими повторами Lights Out → Rollcall. Счётчик `lag`
показывает максимум времени NPC-цикла и сбрасывается раз в пять секунд;
сортировка в этот таймер не входит. Сильное ускорение на любой нагрузке
не гарантируется, особенно на коротких путях.
